# Proyecto Web – Tienda de Calzado

## Descripción del proyecto

Este repositorio contiene el desarrollo de una página web dedicada a una tienda ficticia de calzado. Se trata de un trabajo realizado para la asignatura **Diseño de Interfaces Web**, en el que colaboramos en equipo para diseñar y desarrollar una página web utilizando tecnologías básicas de desarrollo frontend.

El objetivo principal del proyecto es poner en práctica los conocimientos adquiridos durante la asignatura, trabajando con **HTML5 y CSS3** para crear una interfaz visual atractiva, y el trabajo en equipo con grupos de trabajo.

## Objetivos

- Diseñar una página web estructurada mediante HTML5.
- Aplicar estilos y diseños utilizando CSS3.
- Crear una interfaz intuitiva y fácil de navegar.
- Organizar los contenidos en diferentes secciones y páginas.
- Trabajar en equipo y coordinar el desarrollo del proyecto.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** diseño, estilos, distribución y adaptación responsive.
- **Git y GitHub:** control de versiones y colaboración entre los integrantes del equipo.

## Secciones de la página web

La página web está organizada en diferentes apartados:

- **Inicio:** página principal de la tienda.
- **Hombre:** sección dedicada al calzado masculino.
- **Mujer:** sección dedicada al calzado femenino.
- **Niño:** sección dedicada al calzado infantil.
- **Novedades:** presentación de los últimos lanzamientos.
- **Ofertas:** productos disponibles con descuentos.
- **Sobre nosotros:** información sobre la tienda y sus datos de contacto.

## Trabajo en equipo

Este proyecto se ha desarrollado de forma colaborativa con compañeros de clase, repartiendo las tareas de diseño y desarrollo de las diferentes secciones de la página web.

La utilización de GitHub permite mantener el código organizado, compartir los avances y facilitar la colaboración entre los integrantes del grupo.

**Diseño de Interfaces Web**

## Ejecución del proyecto

Para visualizar la página web:

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
